# Arquitetura de dados: dbt + autosserviço

Mapa interativo e artigo sobre como organizar um projeto dbt para que analistas, cientistas, sistemas e agentes de IA se sirvam sozinhos, todos consumindo a mesma definição de negócio.

- `artigo.html`: artigo "Do dado bruto ao autosserviço"

Site estático, sem build. Publicado com GitHub Pages a partir da branch `main`, pasta raiz.
